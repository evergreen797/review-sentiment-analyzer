# Website Contact & Email Finder (Python)

Estrai email, telefoni e social da siti aziendali in modo automatico. Perfetto per lead generation B2B, sales team e agenzie.

## Cosa fa questo Actor

- Estrae **email** (info@, contact@, nome.cognome@, ecc.)
- Trova **numeri di telefono**
- Identifica **link social** (LinkedIn, Instagram, Facebook)
- Estrae **indirizzo** se presente

## Input

Lista di URL di siti web:
```json
{
  "websites": [
    "[https://ristoranteXYZ.it](https://ristoranteXYZ.it)",
    "[https://agenziaimmobiliare.com](https://agenziaimmobiliare.com)",
    "[https://shopmoda.it](https://shopmoda.it)"
  ]
}
